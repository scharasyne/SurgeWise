# QC weekly barangay reconstruction v1

Generated by [notebook 06](../../../notebooks/06_weekly_barangay_reconstruction.ipynb)
with [pure tested math](../../../scripts/generate_weekly_barangay.py).
Run the notebook from the repository or `notebooks/`; its final cell regenerates
these files. See [execution instructions](../../../notebooks/README.md).

Both weekly CSVs have 118,144 rows: 142 barangays × 16 years × 52 source blocks.
They are **modeled allocations**, not observed weekly barangay cases.

The annual subtotal and QC weekly sum disagree in all 16 years. This
annual-preserving policy **scales** the QC weekly profile; `trial_weekly_target`
is not `qc_observed_weekly_cases`. Median estimates cannot resolve that conflict.
The median scenario adds 193 assumed annual cases across the 39 missing cells.
The raw extract contains no explicit annual zeros; whether blanks encode omitted
zeros or unreported counts requires provider clarification.

Selected beta +0.5 and rainfall lag four source blocks are assumptions. Pre-2016
Tracker-scale settlement values are extrapolated; the original Evolution/Tracker
master is not harmonized. Within-year inputs make this retrospective only.
The original Drive trial's expected allocations agree within 7.2e-10 cases;
six rounded cells differ, with both sets of margins still exact.

Do not use these tables as observations for model validation or replace runtime
forecast/simulation inputs with them automatically. Review redistribution terms
in the source documentation before publishing. Raw inputs and original generated
trial remain separately preserved under `data/raw/`.
